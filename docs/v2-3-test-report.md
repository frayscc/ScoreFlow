# V2-3 验证报告：真实预览、演示重置与 PDF 批注

验证日期：2026-09-14

## 完成范围

- 复核页直接嵌入识别引擎保存的完整校正 PNG，并可切换识别叠加层，不以浏览器 PDF 预览代替 OMR 输入。
- 叠加层用颜色、形状和文字三重表达：圆圈加斜线、方框加 X、菱形加问号；非空槽位均可点击放大和人工改判。
- 全空白页显示独立警告，采用按钮明确写为“确认采用空白识别结果”；页面移除要求填写原因。系统仍不自动采用、删除或入账。
- schema v11 增加演示项目标记和归档状态。49 人演示项目含 7 个完整小组、7 名本组组长和“演示第1周”草稿；重置创建全新项目 ID，旧演示项目保留但从日常列表隐藏。
- 正式项目从不获得演示重置身份，也没有一键清空入口；旧演示纸表短编号无法在新演示项目下解析。
- PDFium 300 dpi 栅格化显式启用 `draw_annots=True`，同时处理普通页面内容和 PDF Ink 批注层。
