# 开发进度

更新时间：2026-09-14

## V2-1：多格式名单、周期分组与草稿（已完成）

- 名单主入口支持空格、全角/半角逗号、顿号、Tab、可选“号”字及全角数字；`01` 与 `1` 按同一学号处理。
- 实时预览显示新增、不变和姓名差异；错误定位到原始行，重复学号阻止提交，重名仅提示。
- 增量重复导入按学号幂等保存：不删除未出现学生，不覆盖已有姓名或清空分组。
- 周期分组工作台支持待分组池、拖拽移动、组内排序、多选批量移动、搜索、返回待分组、设定组长及最近 20 次本地撤销。
- 分组草稿持久化到 SQLite schema v9，允许不完整保存并在重启后恢复；乐观修订号防止旧页面覆盖新草稿。
- 49 人/7 组周期开始前强制全员唯一归组、每组 7 人且各有 1 名本组组长；通用名单导入不将 49 人写死。
- 周期开始后只读快照；后续周期的分组调整不改写已签发纸表和历史归属。
- 已对 V1 数据库副本完成 v8→v9 迁移校验，业务记录数与外键完整性保持。
- 49 人虚构演示截图：`docs/images/v2-roster-paste.png`、`docs/images/v2-grouping-workbench.png`。
- 验证报告：`docs/v2-1-test-report.md`。
- GitHub 公开仓库已提前建立；Actions、平台图标、便携包与 Release 仍按 V2-4—V2-6 阶段完成。

## V2-2：导入记录、删除、撤销与新版本（已完成）

- 新增按导入文件分组的“导入记录”，展开可见 PDF 各页、周期、纸表号、面别、识别状态、有效次数与预计分值影响。
- 支持状态筛选、实际校正图预览/复核、失败或未采用页重新识别、取消确认、单页及批量移除。
- 完全重复文件作为独立导入事件显示且不重复处理；内容变化的同表同面作为新候选版本，采用时不会叠加旧版。
- 删除当前采用页后该面回到待扫描，不自动改用旧候选；删除非当前候选不影响已采用版本和另一面。
- 多页 PDF 可独立删除一页，其他页及共享原文件继续保留；最后一页删除后清理无引用原文件，允许同一文件重导。
- 已入账页面（包括 0 分空白表）不能直接删除；批量预检先列出需撤销纸表数、影响人数和净分值，确认后在同一事务撤销整表并从活动列表移除。
- 已入账识别证据采用软移除保留历史；未入账页面、槽位及无引用文件可真正清理。
- 识别中删除会设置持久化删除请求，工作线程在安全页边界停止并清理，防止删除后迟到写回。
- SQLite schema v10 保留 V1/V2 历史数据与 Scorepack 恢复兼容性。
- 验证：59 项 pytest 通过，前端生产构建通过；详见 `docs/v2-2-test-report.md`。
- Windows Actions 便携包与 GitHub Release 仍属于 V2-5/V2-6，将按用户要求以 GitHub 托管 Windows Runner 真实构建后发布。
