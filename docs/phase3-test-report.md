## 交付范围

- SQLite schema v6：扫描任务、不可变原文件、识别版本、槽位自动/人工判定、纸面备注和审计事件。
- PDF、JPG、JPEG、PNG 批量导入；单文件 250 MB、PDF 200 页、单页 1 亿像素保护。
- 容量为 4 的有界队列与单工作线程；逐页栅格化、真实页数进度、取消请求及异常退出恢复。
- 页面二维码独立识别项目、周期、纸表、模板和正背面，不依赖文件顺序或页码奇偶。
- 0°/90°/180°/270°方向处理、四角定位及透视校正；原文件与校正 PNG 分开留存。
- 分辨率、清晰度、曝光质量提示；缺失定位点、错项目、周期/模板不匹配明确失败。
- 四态槽位结果：空白、两种斜线、X、待复核；跳格不作为异常。
- 疑点优先复核、槽位上下文、完整校正图、纸面备注区、键盘快捷键、可选电子备注和预计分数影响。
- 无法读取二维码时输入纸表短编号与面别，不进行静默身份猜测。
- 空白面确认及有原因的撤回；同一业务面重扫保留候选版本，只能采用一个版本。
- 本阶段仅“采用复核版本”，不会产生积分流水；可靠入账属于 Phase 4。

## 验收用例证据

- 乱序/缺面：背面图片先导入后，再独立补正面，身份和面别均正确；单面可单独停留在候选状态。
- 旋转：180° 页面二维码恢复为正向并识别正面；实现同时尝试四个直角方向。
- 重复：相同内容换文件名由 SHA-256 提示重复；同一纸表面不同内容保留多个候选版本，采用新版会撤销旧版的采用标记。
- 错项目：两个页面均被拒绝，错误明确为“页面属于其他项目”。
- 严重裁切：二维码仍在但下方定位点缺失时页面失败，不静默套用模板。
- 人工复核：存在 `review` 槽位时采用操作被拒绝；人工指定四态之一后可采用。
- 空白冲突：确认空白后识别出非空记录时阻止采用；填写原因撤回后才可继续。
- 端到端：真实生成的双面 PDF 经队列导入，2 页、3185 个观察值全部持久化，空白计数分别为 1715 和 1470。
