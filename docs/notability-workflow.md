# Notability / 电子笔迹工作流

本流程用于把 ScoreFlow 纸表导入支持 PDF 批注的笔记软件填写，再导回系统。真实 Notability 导出仍需用户设备验收；程序化 PDF Ink 批注与普通页面内容已经纳入自动回归。

1. 在 ScoreFlow 中开始周期并下载纸表 PDF。不要裁页、旋转、改纸张尺寸或删除二维码和四角黑色定位块。
2. 将 PDF 导入 Notability。建议使用黑色实线笔，笔宽约 0.5—1.0 mm；每个小格只写一条清晰的 `/` 或 `\`，作废时写完整 `X`，允许跳格。
3. 通过 Notability 的“共享/导出 → PDF”导出，保留原始 A4 页面。不要导出截图、低分辨率图片或只含背景而丢失批注的 PDF。
4. 在 ScoreFlow 的“扫描导入”选择导出的 PDF。系统以 PDFium 在 300 dpi 栅格化页面，并明确包含 PDF 批注层和页面内容层。
5. 打开“预览/复核”。上方大图就是识别引擎实际处理的校正栅格图；可切换识别叠加层。绿色圆圈加斜线、蓝色方框加 X、橙色菱形加问号分别表示有效斜线、作废和待复核，信息不只依赖颜色。
6. 点击任一非空槽位可放大并修改分类。全空白结果会显示醒目提示，必须明确点击“确认采用空白识别结果”，也可填写原因后移除此导入页；系统不会自动采用或自动删除。
7. 同一纸表增加笔迹后再次导出并导入，会形成新的候选版本。采用新版时不会把两个版本的次数相加。

如实际导出中笔迹在 Notability 可见、但 ScoreFlow 实际栅格预览不可见，请保留原 PDF，不要反复转换，并记录 Notability/iPadOS 版本、导出选项和页面数量用于兼容性排查。

## 仍需人工验收

- 一份真实 Notability 导出的原始 PDF：空白、一条斜线、跳格两条斜线加一个 X、修改后再次导出。
- A4 100% 双面打印后用 0.5 mm 黑笔填写，再以 300 dpi 扫描。
- 核对真实样本的识别准确率、需复核数量、处理耗时与内存峰值。
