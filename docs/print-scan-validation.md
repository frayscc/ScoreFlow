# Phase 1 打印与扫描验收

1. 打开 `var/phase1/ScoreFlow-演示周期-纸表01.pdf`，选择 A4、双面、长边翻转、实际大小或 100%，关闭“适合页面/缩放”。
2. 用直尺核对页面校准线；槽位应为 3.5 mm，学生行高应为 4.8 mm。记录打印机型号、驱动和实测偏差。
3. 用常见 0.5 mm 黑色或蓝色中性笔填写 `/`、`\\`、`X`，包含跳格、轻笔、靠近槽边等情况；不要填写到二维码和四角定位块。
4. 以 300 dpi 灰度或彩色扫描正反面，关闭会改变页面几何的自动裁边；保留原始 PDF/PNG。
5. 将文件放入单独测试目录后运行识别。人工制作逐槽真值，分别统计空白误报率、斜线召回率、X 识别率、自动接受错误率与转人工比例。

建议首轮至少 10 个扫描面、300 个有效斜线与 100 个 X，并保留未参与阈值调整的验证样本。模拟图只用于程序回归，不能替代以上实扫结论。
