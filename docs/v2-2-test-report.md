5. 识别中请求删除后，任务到达安全页边界后取消，不留识别页、资产行或迟到写回；同文件随后可重导。
6. 未采用页可基于保留的原文件重新识别；完全重复导入会记录当次文件名，但不重复生成页面或积分。
7. schema v6 逐步升级到 v10，新列和原有入账表均存在；Scorepack 整包回归通过。
8. 人为在“撤销后、移除前”注入数据库失败，整个事务回滚：纸表仍为已入账、原批次仍有效、没有半份反向批次，识别证据仍为当前采用。

## 数据一致性结论

- 删除扫描记录不删除 `paper_sheets`。
- 当前面被移除后恢复 `missing`，不静默采用其他版本或确认空白。
- 已入账证据不物理删除；活动列表和审计历史区分。
- 撤销与移除使用同一 SQLite 事务，失败时不留半份反向账或半份状态。
